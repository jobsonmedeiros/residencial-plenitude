O site está pronto para iniciar

Esta página foi aberta como arquivo, então o navegador não consegue carregar a aplicação. Inicie o servidor local para visualizar o catálogo e o painel.

  1. Abra esta pasta no VS Code.
  2. Abra Terminal → Novo Terminal.
  3. Execute npm install e depois npm run dev.
  4. Abra no navegador o endereço local mostrado no terminal (geralmente http://localhost:5173).

Se o terminal disser que npm não é reconhecido, instale o Node.js LTS e reinicie o VS Code. Para carregar os imóveis, configure também o Supabase conforme o README.md.
